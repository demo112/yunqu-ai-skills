2026年 Claude Code 完全入门指南：从安装到高效开发

2026年5月14日 · 教程 · 15 分钟阅读

Claude Code 是 Anthropic 推出的命令行 AI 编程助手，能直接在终端中帮你写代码、调试、重构、运行命令。本文从零开始，手把手教你用好 Claude Code。

一、什么是 Claude Code？

Claude Code 是一个运行在终端的 AI 编程工具。不同于 Cursor 或 GitHub Copilot 的"补全"模式，Claude Code 更像一个 全能编程搭档：

  • ✅ 读取整个项目代码，理解上下文
  • ✅ 直接执行终端命令（git、npm、docker...）
  • ✅ 修改文件、创建文件、运行测试
  • ✅ 支持 Skills（自定义专家行为）
  • ✅ 支持 MCP（连接外部工具和数据源）
  • ✅ 支持 Hooks（在工具调用前后触发自定义逻辑）

二、安装（2 分钟）

# 使用 npm 全局安装
npm install -g @anthropic-ai/claude-code

# 验证安装
claude --version

# 启动
claude
💡 提示：需要 Node.js 18+。如果用 nvm：nvm install 18 && nvm use 18

三、基本使用

启动后，直接用自然语言描述你要做什么：

四、Skills 系统（核心功能）

Skills 是 Claude Code 最强大的功能之一。它让你可以为 Claude 添加"专业知识"。

什么是 Skill？

一个 SKILL.md 文件，包含结构化指令。放到 .claude/skills/ 目录下，Claude 自动加载。

如何安装别人写好的 Skill？

# 下载一个 Skill
mkdir -p .claude/skills/code-review
curl -o .claude/skills/code-review/SKILL.md \
  https://raw.githubusercontent.com/demo112/yunqu-ai-skills/main/skills/02-code-review-sensei/SKILL.md

# 重启 Claude Code 即可使用
claude

五、MCP 集成

MCP (Model Context Protocol) 让 Claude Code 连接外部工具和数据源。

# 配置 MCP Server（在 .claude/settings.json 中）
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/dir"]
    }
  }
}

配置后，Claude Code 可以直接访问这些外部资源，极大扩展了能力范围。

六、Hooks（高级功能）

Hooks 让你在 Claude 执行操作前后运行自定义脚本：

  • PreToolUse — 在工具调用前触发（可以做安全检查）
  • PostToolUse — 在工具调用后触发（可以做日志记录）
  • Notification — 在 Claude 需要通知你时触发
💡 安全 Hook：推荐安装 安全审查 Skill，它会在 Claude 执行危险命令（rm -rf、DROP TABLE）前自动拦截。

七、高效使用技巧

1. 用 CLAUDE.md 定义项目规范

在项目根目录创建 CLAUDE.md，定义技术栈、代码规范、常用命令。Claude 每次启动都会读取。

2. 分阶段处理大任务

不要让 Claude 一次做太多。拆分为多个步骤，每步确认后再继续。

3. 用 /compact 管理上下文

长对话会消耗大量 token。定期 /compact 压缩历史上下文。

4. 善用 Skills 堆叠

同时加载多个 Skills 获得复合效果：Code Review + Security Audit = 全方位代码审查。
